# ServiceOil

Сервис для просмотра и сравнения региональных цен на топливо и расчёта бюджета заправки. Позволяет выбирать регион, вид топлива и период, просматривать историю цен и рассчитывать стоимость закупки заданного объёма или заправки техники.

## Стек

- Java 21, Spring Boot 4.1.1.
- Spring Web MVC, Spring Data JPA / Hibernate, Jakarta Validation.
- PostgreSQL, Flyway.
- Lombok, Maven.
- HTML, CSS, JavaScript.
- Docker Compose для запуска базы данных.
- JUnit 5, Mockito и H2 для тестирования.
